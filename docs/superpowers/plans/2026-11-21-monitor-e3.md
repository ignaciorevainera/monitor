# Monitor — E3 (Instalador, upgrade in-place y retiro de TraySense) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `dist\Monitor-Setup-0.1.0.exe` (Inno local), reemplazar el install viejo de BatteryHub in-place (mismo AppId), migrar una vez los settings de TraySense, retirar TraySense (tarea + Programa Files), y dejar autostart y helper apuntando al install real. Monitor sigue sin admin; TraySense desaparece; PawnIO queda (lo usa el helper).

**Architecture:** Inno per-user (sin UAC) con AppId heredado; `[InstallDelete]` limpia exes viejos; el `[Code]` de autostart se extiende para reescribir **cualquier** valor que apunte a un exe viejo o al build del repo, no solo los nombres predecesores. Migración TraySense = lectura única al startup solo si `MetricsWhere` no existe. Retiro de TraySense y re-registro de la tarea del helper = pasos elevados manuales con UAC (usuario presente).

**Tech Stack:** Inno Setup 6/7 (instalado local vía winget), PowerShell, schtasks runas, MinGW-w64.

**Spec:** `docs/monitor-spec.md` (Etapa 3).

## Deltas aplicados

- El exe viejo instalado **no responde a `--quit`** (E0): el upgrade corre con la app cerrada (Stop-Process).
- **Autostart actual apunta al repo** (`...\battery-monitor\Monitor.exe`) y la tarea `MonitorTempHelper` también (activación hecha desde el build del repo): E3 re-apunta ambos al install.
- PawnIO **no se desinstala**: el helper depende de él.
- `make && make test` ~10 min; scripts bash complejos por archivo `.sh`, no inline; orquestador toma cierres colgados.
- Reviewer fresco por tarea.

## Global Constraints

- **Mismo AppId** `{7E0B5C2A-3F4D-4C8E-9B61-2D5A8F1C4E93}`; `PrivilegesRequired=lowest` (per-user, sin UAC de instalación).
- Installer incluye: `Monitor.exe`, `Monitor.TempHelper.exe`, HeadsetControl, `LICENSE.txt`, `THIRD_PARTY_NOTICES.txt`. NO crea la tarea del helper (la activación de la app la crea).
- Datos intactos: registro `Software\WirelessBattery`, `battery_history.tsv`, carpeta `%APPDATA%\WirelessBattery\lang`.
- Migración TraySense: **solo si `MetricsWhere` no existe**; nunca pisa config existente; flag `MigratedTraySense=1` en ambos casos. `Mode`/`ShowOn` descartados.
- Retiro TraySense: borrar tarea `TraySense` y `C:\Program Files\TraySense\TraySense.exe`; **PawnIO se queda**; `HKCU\Software\TraySense` puede quedar (inerte) o borrarse tras la migración — pin: se deja.
- Build de prueba: `VERSION=0.1.0 CHANNEL=dev` (sin firma/updater).
- **Tarea 2 (reemplazo real del install) y los pasos elevados requieren confirmación explícita del usuario antes de ejecutarse.**

## Review Focus

1. **Autostart re-apuntado**: cualquier valor viejo (WirelessBattery.exe, BatteryHub.exe, o el Monitor.exe del repo) queda apuntando al instalado. Pin: T1 + verificación T2.
2. **Bundle completo**: el setup y el portable incluyen ambos exes; `[Files]` del iss los lista. Pin: T1 + reviewer.
3. **Migración segura**: con `MetricsWhere` existente no toca nada; sin él, mapea `Mask2` bits→7 locations, `Interval`→`MetricIntervalMs`, `Offset`→`TaskbarOffset`; flag idempotente. Pin: T3 + reviewer.
4. **Retiro limpio**: sin tarea `TraySense` viva, sin exe en Programa Files, PawnIO Running, helper funcionando. Pin: T3 + humano.
5. **Nada de datos perdidos**: registro/historial/lang intactos tras el upgrade. Pin: T2 + humano.
