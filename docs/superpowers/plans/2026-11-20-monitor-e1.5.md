# Monitor — E1.5 (Interacción del widget) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Clic derecho abre el menú y clic izquierdo abre el Administrador de tareas; el hover del strip se anima in/out con el estilo nativo de Windows 11.

**Architecture:** Dos cambios aislados a la capa de interacción del widget. El clic se diferencia por `wParam` en el mensaje existente (`WM_WIDGET_CLICK`). El hover animado memoiza el layout del strip (piezas con máscaras ya rasterizadas) y por frame solo recompone píxeles con el alfa actual; un timer de 16 ms vive únicamente durante la animación.

**Tech Stack:** C++17/Win32, GDI/UpdateLayeredWindow, MinGW-w64 (`$env:MSYSTEM='MINGW64'` antes de `bash -lc`).

**Spec:** `docs/monitor-spec.md` (D9 hover, D12 clics se actualizan en Task C).

## Deltas desde la Etapa 1

- Toda verificación visual es humana; las scriptables son build + `make test` completo.
- `Monitor.exe` puede estar corriendo: cerrarlo (`Monitor.exe --quit`, fallback `Stop-Process -Name Monitor`) antes de cada build.
- Reviewer fresco por tarea: en la E1 encontró un bug real que el builder no vio.

## Global Constraints

- Internos heredados intactos (clase, mutex, raíz de registro, Run value, carpetas).
- Sin settings nuevos de usuario para el hover: tiempos fijos 100 ms in / 180 ms out, ease-out cúbico, alfa objetivo 20/26 (light/dark) — réplica del feel nativo W11.
- Respetar la preferencia del sistema: `SPI_GETCLIENTAREAANIMATION` en FALSE ⇒ hover instantáneo, sin timer.
- Timer solo durante la animación; prohibido un timer idle. Prohibido crear fuentes/máscaras GDI por frame (el cache lo garantiza).
- Alcance: strip primario + espejos. Bandeja sin cambios. Tooltip y menú existentes intactos.
- El menú conserva la entrada "Open Task Manager".

### Task B: Hover animado estilo W11

**Files:**
- Modify: `src/widget.cpp` — estado de hover (actual `bool g_hover` y `Mirror::hover`), `SetHover`, `WidgetProc` (`WM_MOUSEMOVE`, `WM_MOUSELEAVE`, `WM_TIMER`), `PaintStrip`/`Paint`/`PaintMirror`/`PaintAll`, `SetItems`/`SetLightTheme`/`SetStacked` (invalidación), `Destroy`.
- Modify: `docs/monitor-spec.md` — D9 (hover se mantiene y se anima, 100/180 ms, respeta la preferencia del sistema).

**Interfaces (estado por ventana):**
```cpp
constexpr int kHoverInMs = 100, kHoverOutMs = 180;
constexpr UINT_PTR TIMER_HOVER = 4;
// primaria: g_hoverT (0..1), g_hoverFrom, g_hoverStart (ULONGLONG), g_hoverDir (-1/0/+1)
// espejos: los mismos cuatro campos en Mirror, reemplazando bool hover
void StartHover(HWND h, bool on);              // reemplaza SetHover
float HoverStep(ULONGLONG now);                // progreso normalizado + ease-out cúbico
void PaintStrip(HWND, HWND taskbar, SIZE&, int maxW, float hoverT);
```

**Diseño obligatorio:**
1. **Timer**: `SetTimer(h, TIMER_HOVER, 16, nullptr)` al iniciar una transición; `KillTimer` al alcanzar 0 o 1. Progreso por `GetTickCount64` (no pasos fijos). `SPI_GETCLIENTAREAANIMATION` en FALSE ⇒ fijar el valor final y pintar una vez, sin timer.
2. **Easing**: `ease(p) = 1 - (1-p)^3`; in: t 0→1 en 100 ms; out: t 1→0 en 180 ms. Alfa del `roundRect` = `(int)(base * t)` con base 20 (light) / 26 (dark).
3. **Cache del layout**: memoizar el resultado de `Layout()` (más la resolución de overflow: piezas finales, W/H, `g_hiddenTip`) bajo una clave que incluya: firma de ítems (mismos campos que usa `Layout`), `g_light`, DPI, `g_stacked`, `g_vertical`, tamaño del taskbar y `maxW`. Invalidar la clave en `SetItems`, `SetLightTheme`, `SetStacked`, cambio de DPI/tamaño en `Reposition` y cambio de `g_maxW`. Con cache válida, los frames de animación no llaman `Layout` ni crean fuentes/máscaras.
4. **Pintado por frame**: `PaintStrip` con cache válida recompone el `Canvas` (fondo + hover con alfa t + piezas cacheadas) y llama `UpdateLayeredWindow` — una pasada de píxeles, sin GDI de texto. El hover se dibuja antes de las piezas (stacking actual: debajo del texto).
5. **Espejos**: estado independiente por ventana; `WM_MOUSEMOVE`/`WM_MOUSELEAVE` del espejo mueve solo su alfa. `PaintAll`/`Reposition` mantienen posicionamiento.

**Review Focus de esta tarea:** (a) cero GDI (CreateFont/RenderMask) por frame; (b) invalidación completa del cache (ítems, tema, DPI, tamaño, maxW/compacto); (c) timer muerto al terminar y en `Destroy`, sin doble arranque; (d) hover debajo del texto; (e) sin animación cuando el sistema la desactiva; (f) espejos independientes.
