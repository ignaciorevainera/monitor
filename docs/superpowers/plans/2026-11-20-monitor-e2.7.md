# Monitor — E2.7 (Etiqueta de componente: Icono / Palabra / Ambos) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Control global del estilo de etiqueta para todas las métricas del strip: **Icono** (default, look actual), **Palabra** (CPU, RAM, GPU, VRAM, SSD; temps CPU°, GPU°, SSD°) o **Ambos**, con la palabra en color apagado para no competir con el valor.

**Architecture:** Un `word` corto por métrica en `MetricSpec`, un REG_DWORD global con radio en el submenú System metrics (zona libre de IDs), y una pieza más en `Layout`. `WidgetItem` gana `word` + estilo → `SameItems` (regla del cache). Bandeja y tooltips sin cambios.

**Tech Stack:** C++17/Win32, MinGW-w64 (`$env:MSYSTEM='MINGW64'` antes de `bash -lc`).

**Spec:** `docs/monitor-spec.md` (D10 se actualiza en la Tarea 1).

## Global Constraints

- Default **Icono (0)**: con default el render es byte-idéntico al actual.
- Palabras cortas exactas: `CPU`, `CPU°`, `RAM`, `GPU`, `GPU°`, `VRAM`, `SSD°` (temps con grado). El nombre largo ("CPU usage") queda en tooltip/menú.
- Palabra en **alfa 170** (vs 255 del valor) — apagada pero legible; mismo font del valor.
- En **compacto** la palabra se descarta primero; el valor nunca se oculta por la palabra.
- La temp inline agrupada (E2.5) NO agrega palabra — el uso ya identifica al componente.
- Bandeja sin cambios (número-only). `i18n.cpp` intacto (selección automática).
- IDs nuevos 151-153, sin colisión con ningún rango existente.
