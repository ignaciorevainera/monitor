# Monitor — E2.8 (CPU die-temp vía helper elevado) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Temperatura real de CPU (die) sin elevar Monitor: `Monitor.TempHelper.exe` corre elevado por una tarea al logon, lee el sensor vía PawnIO (módulos embebidos) y publica el valor por un archivo atómico; Monitor lo consume en el sampler. UAC una sola vez, al activar.

**Architecture:** Helper separado (build target nuevo) + IPC por archivo (`%LOCALAPPDATA%\Monitor\cpu_temp.bin`, escritura atómica con rename) + tarea programada `HighestAvailable` creada vía `schtasks` elevado (port del XML de `traysense.c:1619-1650`). Monitor sigue `asInvoker`; intenta abrir el device directo primero (futuro-proof), y solo con `ERROR_ACCESS_DENIED` ofrece instalar el helper.

**Tech Stack:** C++17/Win32, PawnIO (`\\?\GLOBALROOT\Device\PawnIO`), RCDATA embebido, MinGW-w64.

**Spec:** `docs/monitor-spec.md` — **revierte D2 parcialmente**: CPU die-temp vuelve vía PawnIO, PERO solo a través del helper elevado; Monitor nunca se eleva. GPU/SSD/temas siguen sin admin. D2 se actualiza en la Tarea 1.

## Global Constraints

- **Monitor nunca elevado** (`asInvoker` intacto). Solo el helper corre `HighestAvailable`.
- UAC **una única vez**: al activar (crear tarea + lanzar helper). Nunca en arranques normales.
- Port verbatim de `vendor/traysense/traysense.c:368-450` (pio_exec, pio_init, pio_temp: CPUID vendor, `ERROR_ACCESS_DENIED`→NoAdmin, RCDATA 101=Intel/102=AMD, tjmax MSR 0x1A2, SMN 0x00059800 con el bit -49, mutex `Global\Access_PCI`).
- Archivo IPC: struct fija `{ uint32 magic 0x4D4F4E54; uint64 tick; double tempC }` en `%LOCALAPPDATA%\Monitor\cpu_temp.bin`; atomic write (`.tmp` + `MoveFileEx` replace); freshness < 10 s; stale ⇒ fallback.
- Prioridad de fuentes para CpuTemp: **helper fresco > Thermal Zone > `--`** (en esta placa Thermal Zone no existe).
- Helper: single-instance (`Local\MonitorTempHelper`), sin ventana (`-mwindows`), loop 2 s, sin dependencias nuevas de linkeo.
- Installer/empaquetado del helper: **NO en esta etapa** (va en E3).
